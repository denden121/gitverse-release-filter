# GitVerse — фильтры релизов

Расширение для Chromium-браузеров (Manifest V3), которое добавляет сводку по релизам, фильтры и сведения о ревью в список pull requests GitVerse.

Текущая версия: **1.5.0**. По умолчанию работает в репозитории `dgurachevskii/manager`.

## Возможности

- Сводка по релизам из названий PR и фильтрация по нажатию на счётчики.
- Фильтры по участию, ревью, замечаниям, ошибкам CI и Draft.
- Сортировка по релизу, возрасту PR, одобрениям и открытым замечаниям.
- Счётчики открытых и решённых замечаний, предпросмотр комментариев.
- Настраиваемый логин для фильтров «Мои PR» и «Ждут моего ревью».
- Оформление GitHub Dark для списка и страниц PR; переключатель находится в настройках фильтров.

## Установка

1. Скачайте репозиторий через **Code → Download ZIP** и распакуйте его или клонируйте через Git.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение** и выберите папку с `manifest.json`.
5. Откройте https://gitverse.ru/dgurachevskii/manager/pulls и войдите в GitVerse.
6. В настройках панели укажите свой логин.

Сборка и установка зависимостей не нужны. После изменения файлов нажмите кнопку перезагрузки расширения и обновите вкладку GitVerse.

## Ограничения и данные

Фильтры и сводка учитывают только PR на текущей странице. Релиз определяется по версии в конце названия PR, например `Исправление фильтра 1.24` или `Исправление фильтра v1.24.1`.

Расширение читает данные через внутренний API GitVerse с текущей сессией браузера. Отдельные токены не требуются. Настройки сохраняются в `localStorage` GitVerse, загруженные комментарии — в памяти вкладки. Код не отправляет данные сторонним сервисам.

Одобрение ревью не гарантирует готовность PR к слиянию. Неизвестные статусы в сводке отмечаются символами `—` или `+`. Работа зависит от текущей разметки и внутреннего API GitVerse.

## Другой репозиторий

Замените путь `dgurachevskii/manager` в `manifest.json`, `popup.html` и `release-filter.js`. В JavaScript также обновите регулярное выражение маршрута страницы PR (переменная `detail`) и при необходимости логин по умолчанию в `defaults.me`.

## Файлы

- `manifest.json` — настройки расширения и адреса страниц.
- `release-filter.js` — панель, фильтры, запросы и предпросмотр комментариев.
- `pr-detail.css` — оформление страниц PR.
- `popup.html` — окно расширения со ссылкой на список PR.
